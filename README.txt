LOCATION SHARING — NO BACKEND VERSION

1. Open index.html in a browser to test the page.
2. IP lookup needs internet access and uses a public IP-geolocation service when you press the button.
3. GPS usually requires HTTPS or localhost. A local file may not allow GPS in every browser.
4. To share it, host index.html on an HTTPS static website (for example, a static hosting provider), then share that public URL.
5. This version does not store visits or send a visitor's location to your private viewer dashboard. It shows IP/GPS information on the page itself. A private remote dashboard requires a backend or a third-party service configured for that purpose.
